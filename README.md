# Boca

Boca est un site web de restaurant où l’on peut consulter les différents menus et effectuer des réservations en ligne.

## Démo

👉 [Voir la démo de Boca](https://boca.prb-dev.fr/)

## À propos du projet

- Site web de réservation de table pour un restaurant. 
- Interface orientée utilisateur pour choisir une date, un créneau horaire et le nombre de couverts.
